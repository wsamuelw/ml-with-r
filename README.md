# ML with R

Common Machine Learning algorithms implemented in R — from data prep to model evaluation.

## What's Inside

- **predict diabetes with glm.R** — Logistic regression using GLM to predict diabetes status

## Requirements

- R (>= 4.0)
- `tidyverse`, `caret`, or `tidymodels` (check individual scripts for dependencies)

## How to Run

```r
source("predict diabetes with glm.R")
```

## Why

R was built for statistics. These scripts show how to do ML the R way — clean, readable, and reproducible.
